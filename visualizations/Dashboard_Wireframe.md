# EarthPulse AI Dashboard Wireframe

## Purpose

The EarthPulse AI Dashboard is the primary interface through which users explore environmental trends using NASA Earth observation data.

The dashboard transforms complex environmental datasets into accessible insights through visualizations, environmental indicators, and AI-generated explanations.
