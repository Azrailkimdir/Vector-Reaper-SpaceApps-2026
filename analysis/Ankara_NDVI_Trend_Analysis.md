# Ankara NDVI Trend Analysis (2000-2025)

## Data Source

NASA Earthdata

Product:
MOD13Q1 Version 6.1

Parameter:
NDVI (Normalized Difference Vegetation Index)

Location:
Ankara, Türkiye

Coordinates:
39.9334 N, 32.8597 E

Period:
2000-2025

---

## Objective

Analyze long-term vegetation trends in Ankara using NASA Earth observation data.

---

## Dataset

Raw data file:

datasets/raw_data/Ankara-NDVI-2000-2025-MOD13Q1-061-results.csv

---

## Key Questions

- Has vegetation increased or decreased over time?
- Are drought signals visible?
- How has seasonal variability changed?
- Can environmental risk indicators be detected?

---

## Initial Findings

The dataset contains 25 years of MODIS NDVI observations for Ankara.

The data will be used to:

- Detect vegetation trends
- Measure seasonal variation
- Support EarthPulse AI environmental analysis
- Generate AI-assisted environmental insights
