# Notebooks

This directory contains Jupyter notebooks used for data exploration, preprocessing, analysis, and prototype development for the EarthPulse AI project.

---

## Purpose

The objective of this folder is to document the analytical workflow behind EarthPulse AI and provide reproducible research throughout the project lifecycle.

Notebooks will be used to explore NASA Earth observation datasets, detect environmental trends, and generate insights for visualization and risk assessment.

---

## Planned Notebooks

### 01_Data_Exploration.ipynb

Initial exploration of NASA datasets.

Tasks:

- Dataset inspection
- Missing value analysis
- Data quality assessment
- Variable identification

---

### 02_Temperature_Trend_Analysis.ipynb

Analyze temperature trends over time.

Tasks:

- Historical comparisons
- Anomaly detection
- Trend calculation
- Climate change indicators

---

### 03_NDVI_Analysis.ipynb

Vegetation monitoring using NDVI data.

Tasks:

- Vegetation change analysis
- Land cover assessment
- Trend visualization

---

### 04_Drought_Risk_Assessment.ipynb

Environmental risk evaluation.

Tasks:

- Drought indicators
- Risk scoring
- Risk classification

---

### 05_AI_Insights_Generator.ipynb

Generate human-readable summaries.

Examples:

- Trend explanations
- Environmental alerts
- Risk descriptions
