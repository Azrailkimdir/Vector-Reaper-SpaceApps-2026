# EarthPulse AI Dashboard Mockup

## Purpose

The EarthPulse AI Dashboard is the main interface through which users explore environmental trends using NASA Earth observation data.

The dashboard is designed to transform complex datasets into understandable insights through visualizations, environmental indicators, and AI-generated explanations.
